# Registros de decisiones de arquitectura (ADR)

Copia de los ADR del documento de arquitectura del trabajo final, que es la fuente de verdad: si se cambia una decisión, se cambia primero en el documento.

Cada decisión usa una plantilla MADR 4 simplificada: Contexto (con el atributo de calidad o la restricción que pesa), Decisión, Alternativas consideradas, Consecuencias negativas con sus mitigaciones y una línea de Confirmación que indica cómo se comprueba que la decisión se cumple.
